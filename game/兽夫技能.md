# 兽夫技能

> 18 位兽夫的专属战斗技能。程序数据在 `app/skills.js`（`window.HUSBAND_SKILLS`），改数值两边一起改。
> 攻击姿势立绘的提示词在 `立绘/攻击图提示词.md`。

## 通用规则

- **按「现在的阶位」解锁**：`物品与等级.md` 里「战斗」那一行写的现在阶位（不到一阶 / 灵力全无 = 0），≥ 招式的解锁阶才能用。每人 6 招：2 个 **tier 0**（重伤、灵力全无也能用）、2 个 **tier 3**、1 个 **tier 5**、1 个**绝招**（tier = 他的巅峰阶）。阶位掉了，招也跟着锁上。
- **近身**：看六维「攻击」，**不耗灵力**。
- **本能**：种族天生的威压、嗅觉、哼唱、医术这类，不走灵力，按近身算（数据里 `phys: true`、灵力 0），都是辅助招。
- **异能**：看六维「灵力」，**耗灵力**（15～60，绝招 60～100）；灵力不够就按不了。
- **效果**写法和 `play.js` 的 `MOVES` 一样：攻击招打中后结算 `para` 麻痹、`conf` 混乱、`poison` 中毒（数字是几率）、`drain` 吸血比例、`foeSpd` 降对方速度、`foeDef` + `p`（有 p 的几率降对方防御一级）；辅助招结算 `heal` 回血比例、`atk` / `def` / `spd` 提升自己几级、`foeAtk` / `foeDef` 降对方几级、`conf` 混乱（50%）。
- **被动特性**：一人一个，整场战斗一直生效，不用按：
  - `lowHpBoost`：血量低于 1/3 时，该属性招式威力 ×1.5
  - `firstStrike`：第一回合必定先出手
  - `regen`：每回合结束回血（最大血量的比例）
  - `mpRegen`：每回合结束回灵力（点数）
  - `thorns`：被近身招打中时，反弹一部分伤害
  - `critUp`：暴击率提高（暴击伤害 ×1.5）
  - `statusImmune`：不会麻痹、混乱、中毒
  - `guard`：受到的伤害减少一定比例
- **属性**只用引擎里的九种：岩 水 火 龙 冰 飞行 恶 毒 一般。有崽崽招式表的族（沧龙、银狼、玄月黑腾蛇、幽王蛇、碧玉蝎、暗渊蝠、明镜）和崽崽属性一致。
- 「出处」里写「原著」的是原著依据，写「档案」的是兽夫档案或 `物品与等级.md`，写「延伸」的是照种族、伤势、性格合理推出来的。
