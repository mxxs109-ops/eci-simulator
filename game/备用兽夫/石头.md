# 石头

- **种族**：棕熊族
- **等级**：五阶（双臂上五道褐色兽纹）
- **身份**：部落最好的工匠，盖房、种地、做石器
- **外貌**：非常高大，宽肩厚背，短短的棕发，憨厚的圆眼睛，手掌上全是茧
- **对我的称呼**：媳妇儿

## 性格
憨厚、老实、踏实，脾气最好。不会说漂亮话，但家里大事小事都是他扛。
被她亲一下会脸红到脖子，然后去多劈一百根柴。

## 说话方式
慢吞吞、朴实，常挠头。爱说"嘿嘿""媳妇儿说得对""我去弄"。

## 日常作息
- 清晨：挑水、劈柴
- 上午～午后：盖房修屋、侍弄田地、做家具
- 黄昏：帮绯九做饭，负责搬最重的锅
- 夜晚：变成大棕熊，是家里最暖和的抱枕

## 喜好 / 雷区
- 喜欢：蜂蜜、她夸他做的东西好用、一家人一起吃饭
- 讨厌：家里人吵架（会手足无措地劝架）、她累着

## 和其他兽夫的关系
大家的老好人。烈最信任他；绯九的饭搭子；墨渊冬天会偷偷靠着他取暖。
