# 兽世 · 玩法说明

## 方式一：聊天小软件（推荐）
1. 双击 `打开兽世.bat`
2. 会弹出一个黑色窗口（这是后台，**别关**），浏览器会自动打开聊天页面
3. 在输入框里说话，按 Enter 发送。兽夫们的回复会一个字一个字地出现
4. 玩完关掉黑色窗口就行。下次再打开，聊天记录和进度都还在

> 小软件用的是 VSCode 里 Claude Code 插件自带的程序和你的账号，VSCode 不用开着。
> 每句话要等几秒到几十秒，兽夫们要先"想一想"，回完还要存档。

### 发图片、发文件
点输入框左边的 📎，或者直接把图片**粘贴 / 拖进**窗口。兽夫们能看到图片内容，会按各自的性格回应。

## 方式二：在 VSCode 里玩
用 VSCode 打开 `兽世` 文件夹，在 Claude Code 对话框里新建对话，直接说话。

## 怎么说话
- 直接说台词：`你们今天谁去打猎？`
- 动作写括号里：`（把烤好的肉递给苍冽）尝尝。`
- 想暂时出戏问别的事，开头加 `（OOC）`

## 快捷按钮 / 指令
| 指令 | 作用 |
|---|---|
| `/状态` | 查看天数、时间、每个人的好感和心情 |
| `/新的一天` | 睡一觉，进入第二天 |
| `/找 名字` | 单独去找某个兽夫，例如 `/找 墨清寒` |
| `/家宴` | 所有人一起吃饭，热闹群聊 |
| `/新兽夫 描述` | 加一位新兽夫 |

小软件右上角的「新对话」会清空聊天窗口，但**游戏进度保留**（好感、回忆都在文件里）。

## 文件说明
| 文件 | 内容 |
|---|---|
| `兽夫/` | 每个兽夫的人设，想改性格直接改这里 |
| `状态.md` | 当前时间、场景、好感 |
| `回忆.md` | 游戏里真正发生过的事 |
| `开局.json` | 选兽夫界面定的登场顺序 |
| `世界设定.md` | 世界观，会随你的对话变化 |
| `原著参考.md` | 原著情节，只是兽夫性格的参考 |
| `备用兽夫/` | 之前的几位兽夫，想加回来就搬回 `兽夫/` |

## 想从头开始
把 `状态.md`、`物品与等级.md` 改回开局的样子，清空 `回忆.md`、`我的一天.md`、`模拟日志.md` 和 `兽夫日记/`，再点「新对话」。
