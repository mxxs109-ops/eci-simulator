# 2D 游戏资产提示词（Q 版 · 45° 俯视 · 透明背景）

统一画风：Q 版可爱 2D 游戏风，平涂 + 柔和赛璐璐阴影 + 细深色描边，透明背景（PNG），像星露谷 / 宝可梦那种温馨的游戏小图。所有资产都用同一段「画风」开头，保证放在一起不违和。

生成后的命名和存放：放进 `立绘/2D/`，文件名照每条标题后面写的。GPT 常把灰白格子直接画进图里（假透明），没关系，Claude 会抠掉，原图另存为 `名字-原图.png`。
