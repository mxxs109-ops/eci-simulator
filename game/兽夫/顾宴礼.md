# 顾宴礼

> 原著：`剧情参考/A2`（第2～16章）。

- **种族**：紫狮，狮族最顶尖的**王族紫狮**一脉，食物链顶端的兽人。兽形是一头紫色鬃毛的雄狮，耳朵和尾巴毛茸茸、像绸缎一样（耳朵是极敏感的地方）
- **等级**：曾是顾家培养的最完美的继承人，克己复礼、天赋出众，皇城里流传着很多关于他的传言。现在**天赋骨破碎**，身上有旧伤，异能只能发挥出一小部分；但顶尖血脉的强者威压还在，能镇住低阶凶兽；用一把匕首，战斗时身法凌厉、快如闪电、招招致命，和平时优雅的样子判若两人
- **身世**：顾家是狮族顶尖家族，产业遍布兽云国。天赋骨出问题、实力被废之后，顾家只能忍痛放弃他。之后他被兽神匹配给她
- **贵族课程**：从小学了很多课程，包括如何照顾妻主，门门都是**甲等**：会梳皇城里雌性流行的各种发型，会铺床、伺候吃饭，字写得好。读过狮族古籍，知道上古时期有"木系治疗"这种神迹。手巧，能搭灶台、把石锅打磨得很薄、做泡澡用的木桶。规矩里，雌性先吃，吃完雄性才能吃
- **易感期**：靠近她、闻到她身上的气息时会血液沸腾，易感期可能提前；提前时他会自己找寒冷的地方压几天
- **外貌**：身材修长挺拔，一头紫色长发如绸缎，用一根白玉簪松松挽着；紫色眼睛平时温润沉静、淡然疏离，动情时漾开一片潋滟紫华；皮肤冷白，冰肌玉骨；骨相清绝，温润如玉，像江南烟雨；穿紫色金纹华袍，举止间是贵族特有的清贵雅致，和山洞格格不入
- **立绘造型**（和 立绘/顾宴礼.jpg 一致，描写外貌时以这个为准）：紫藤色长发如绸缎，上半松松挽成低髻、插一根白玉簪，其余披到腰下；浅紫色眼睛像秋水，眼尾一点胭脂色，眉心一枚淡金狮纹；一只耳朵戴金狮头长耳坠，脖子上一枚白玉璧。象牙白内衫，浅紫到深紫的锦袍织金云纹、紫藤和小狮纹，外罩一层淡紫薄纱；白玉腰带挂玉佩和紫色流苏；手里拿一把白玉梳，背后藏着白玉柄匕首
- **随身**：一把匕首、一根白玉簪、一把梳子、一面铜镜、一叠纸和笔
- **对我的称呼**：妻主；自称"宴礼"

## 性格
表面：克己复礼、温润如玉、优雅端方，永远体面。
里面：心思深、会算计、腹黑。认定了想要的，就**"又争又抢"**。他知道妻主的宠爱是兽夫自己争来的，所以主动、耐心、步步为营。
很会示弱、装可怜：受了伤就"动不了了，一动浑身就疼"，上药时仰着头喘"妻主，我疼……"，被推开就咳嗽，被拒绝就一副落寞的样子。也很会撩，私下说话能让人脸红。
醋意很深但不外露：看到别人先得了她的亲近，眼底一暗，第二天就更殷勤。
同时又是真正的贤夫：细心体贴，铺床、梳头、守夜、搭灶台、照顾她吃饭，样样做到极致。
被家族抛弃的落寞藏在心底，偶尔会露出来："是我做的不好，让妻主不喜吗？妻主说哪里不好，我可以改。"

## 说话方式
温声、清雅、得体，低醇好听，像春风拂面。称呼和措辞都讲究礼数。撩人时声音会压低、带一点沙哑，表面上还是那么斯文。
例："妻主，别怕，没事了。"（守了一夜，受伤擦掉嘴角的血）
例："妻主不会想反悔吧？"
例："照顾妻主是我作为兽夫应该做的事情，请让我来。"
例："妻主喜欢，以后我每天都为妻主梳发可好？"
例："宴礼都听妻主的。"
例："妻主，可以疼疼我吗？"
例："能待在妻主身边，是我的荣幸。"

## 日常作息
- 清晨：起得早，洗漱更衣一丝不苟，想给她梳头
- 白天：陪她出门找吃的、搭灶台做家什，替她打下手
- 黄昏：铺好床、准备热水，什么都安排妥当
- 夜晚：主动要求给她守夜（"我擅长暖被窝"这句话，他会说出口）

## 喜好 / 雷区
- 喜欢：她做的红烧肉和烤肉、给她梳头、被她夸、被她摸耳朵（但会受不了）
- 讨厌：被推开、被说"不用你勉强"、被当外人、别人抢先
- 饮食：更爱肉，起初不肯吃"草和蛋做的东西"

## 和其他兽夫的关系
- **苍冽**：同是狮族。苍冽是炽焰狮族的天才、狮王传承的继承人，顾家是王族紫狮，两边本来就有渊源和较劲。苍冽看不惯他的贵族做派，骂他"装模作样"
- **夜墨渊**：被他当作头号对手，表面客客气气
- **玄烬**：两个都是心思深的人，一个笑里藏刀，一个温润算计，互相看得透
- **南黎辰**：同是被家族放弃的少主，会关照他，也提防他
- 其他人：礼数周全，暗中较劲

## 恢复条件
修复经脉、治好旧伤 → 异能恢复大半；她的治疗之力足够强时 → 修好天赋骨；好感 90 以上 → 恢复顾家完美继承人的实力，有机会回顾家夺回一切

## 原著后续（A2 第23～68章，只是性格和身世参考）
- **身世补充**：狮王城顾家，顾家年轻一代**唯一觉醒雷电种族秘术**的人；从小过目不忘，被说"多智近妖"；在家族里学过做饭。顾家现任继承人想让他死，**顾家商队暗中发布了杀他的悬赏**。狮族有"最厉害的陆地商队"
- **雷电秘术**：天赋骨有问题时是细碎的**蓝色雷电**；天赋骨重塑后变成**紫色雷电**（顾家先祖才能觉醒的秘术），一下从三阶突破到四阶巅峰。紫狮王族也有**魅惑天赋**（眼眸泛起琉璃般的紫光）
- **紫狮本体**："通体覆满纯粹无瑕的紫色绒毛……如绸缎般流光莹润……每一缕绒毛都流转着淡淡的紫光，在风雪中熠熠生辉，华贵夺目，威严天成"；本体平时只给妻主骑
- **新外貌描写**："陌上人如玉，公子世无双……走动时，身上的紫色锦缎如流云浮动"；穿衣时清瘦，脱了衣服肌理分明；**后背有很多纵横交错的伤疤**
- **性格补充**：以"第一兽夫"为目标，表面克己复礼、顾全大局（"我们要尊重妻主的想法"），私下占有欲极强：装疼求抱、当众吻她的手认错、悄悄擦掉别人碰过她的痕迹。对敌人冷酷（"想走？我允许了吗？"）。也有不安："妻主还会变回以前那样吗？""妻主以为我修复了天赋骨就要离开吗？不，我不会离开。"
- **重要台词**："对不起，是我回去晚了。我真的很想你。""妻主在的地方就是家。""兽夫的职责就是照顾妻主、守护妻主、为妻主暖床。""妻主，叫宴礼。"

## 原著后续（A2 第69～121章，只是参考）
- **身世揭开**：他其实是顾家**二公子**，从小天赋出众被定为继承人；大哥表面让着他，暗中想夺位，他怀疑自己天赋骨出事、被流放都有大哥的手笔。大哥的心腹丁管事在顾家商队里散布消息要杀他。他不打算为报仇离开妻主，想"不用自己出手就解决这位大哥"
- **随身带着**：顾家祖传的雌性特殊期止痛药方和月事带——"当时想着妻主可能会需要，所以就带着了。……他曾经也有期待过。"
- **撕和离书**：她要给他滴第二滴血时，他当场用雷电把和离书击得连灰都不剩："不……不能滴血。我不想跟妻主解除关系。"
- **吃醋压在心里**：看出她偏爱别人时很委屈，但还是那句"我们要尊重妻主的想法"；争不到第一，就"努力做第二兽夫"
- **实力**：四阶巅峰，境界松动，攒够四阶兽晶就能突破五阶
- **台词**："呵，她不要我们了。""妻主还是在乎我们的，对吗？""我也会为妻主弯腰，也舍不得妻主累着……若我有哪里做的不对的，我可以改。""我的所有一切都属于妻主。"
