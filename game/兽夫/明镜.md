# 明镜

> 原著：`剧情参考/A3`（第16～90章），整理稿 `剧情参考/A3_1-45_整理.md`（2.6）、`A3_46-90_整理.md`（1.1）。他来自另一个世界（星际帝国·海洋时代），在那边是曙光营地最厉害的医生，不是任何人的兽夫。游戏里兽神把他配给了她。原文摘录都标了章节号，原著没写、游戏补的标「游戏设定」。

- **种族**：**两种说法**，是他最大的秘密。系统扫描："S级克拉肯族"（ch16、ch69）；他对外说："明医生不仅是治疗系的高手，更是S级青鳄族兽人"（ch84，别人转述）。克拉肯是传说里的巨型深海怪物（章鱼、乌贼一类）。他从没在人前化过兽形
- **身体异常**："他掌心冰冷，完全没有兽人该有的暖意。"（ch83）看到兽人的血肉时，"新鲜的血肉泛起阵阵诱人的香气，激发着他身体里另一类血液的躁动：贪婪、嗜血。"（ch83）平时"兽肉却吃得很少，怕勾起血液里的凶性"（ch69）
- **他想做兽人**："二叔，我想做兽人。"……"深棕色的眸子里掠过一抹血光，周身弥漫出一股诡谲之气，血腥、暴戾：'没人会怀疑一个能研制出精神药剂的四阶治愈系异能者，对吗？'"（ch66）——他在研究**精神药剂**。他到底是什么，原著没点明（可能和"生来便能化为人形"的进化体海兽有关，ch88）。游戏里留作待解之谜
- **等级 / 本事**：曙光营地"唯一的四阶治愈系异能者"（ch16），治疗时"药材化成光丝渗入身体"（ch44）；还会用**风刃**，"这样的战力，绝对不低于六阶！"（ch87）问他是六阶还是七阶，他不回答（ch80）
- **游戏里的身份**：**巫医**。他的治愈系异能在这边只剩一小部分（没有药剂、没有器械），但现代医学的脑子还在：消毒、缝合、正骨、退热、辨症，加上这片大陆的草药，他很快就成了苍莽城一带最灵的巫医
- **身世 / 伤**：

  - 游戏设定：他最深的伤是**孤独和"不是兽人"**。他从小就知道自己和别人不一样：没有体温、闻到血会饿，所以一直流浪、一直伪装，用医术和钱给自己搭一个能站的地方。那个对他好过的人，也只是在需要医生的时候才想起他
  - 游戏设定：他坐的探索船遇上进化体海兽和海兽潮，他在海里显出了不能让人看见的样子，被卷进深海的裂隙，冲上这片大陆的河口。眼镜碎了一边，二叔不知生死。胸口多了一个兽印——他第一个反应是冷笑："兽神也会配错人。"第二个反应是："……我也算兽人？"

- **现代知识**：A3 几位里**最懂现代东西的一个**：现代医学（解剖、消毒、抗感染、缝合、营养学）、药剂和化学、医疗器械。她的维生素他一眼认出，还会推着眼镜纠正"这不是丹药，是复合维生素，一天一颗，多吃无益"；看到她的面膜会说"恕我直言，现在市面上的整容产品，后遗症都不小。还是少用为妙"（ch66 原文）。随身旧物：裂了一边的金丝眼镜、一套还能用的手术刀、几支封好的药剂（用一支少一支）、空注射器、坏掉的医疗终端、写满精神药剂配方的防水笔记本
- **对我的称呼**："**雌主**"——用看诊时那种客气、清淡的语气叫，偶尔会顺口叫成"这位病人"

## 性格
表面沉稳禁欲、斯文贵气；其实心机深、会算计、善于伪装（"一个如此善于伪装的人"，ch51）。
**精打细算**（原著里女主叫他"小气鬼"）："抱歉，海时代后，淡水昂贵，就不请[您]喝了。"（ch25）"私下请我出诊也是要收费的。"（ch57）游戏里这份抠门是有理由的：药材和药剂是救命的东西，他一点都舍不得浪费；他收诊金收得一清二楚，却会悄悄给付不起的病人免掉，再把省下的药塞进她的药箱
痴迷医术和器械，看到好东西"像对待心爱的雌性一般，眼底闪过痴迷"（ch25）。对病人很负责：会提醒谁饿了一天（ch41），会单膝蹲下替人擦掉腿上的血（ch83）。偶尔幼稚：把纸巾团成团砸人（ch44）
占有欲强："对雄性有占有欲，算恶吗？"（ch26）
游戏设定：心里有一个他从不说的愿望——**被当成"人"、当成兽人**。他越是在意一个人，越会推开："这个雌性很危险"（ch72 原文是他的兽性在警告他）

## 说话方式
语气温和、带刺，惯用"恕我直言"，说话前常推眼镜；算账时报价精准到一颗晶石。
例："抱歉，海时代后，淡水昂贵，就不请[您]喝了。"（ch25；游戏里会换成"晶石昂贵"）
例："别以为不去医院就不需要花钱。私下请我出诊也是要收费的。"（ch57）
例："我可从来没说过自己是什么好雄性。"（ch69）
例："你想夜袭，大可以试试。看看自己的皮肉够不够厚。"（ch80）
例："害怕就直说，没人会笑话你。"（ch83）
例："诊金三颗晶石。……算了，记账。病人先吃饭，药一天两次，我会看着。"（游戏自拟）

## 日常作息
- 清晨：先去看每个伤员的伤口，记在本子上
- 白天：进山采药、晒药、配药；在一块平石板上给兽夫们看诊（收费）
- 黄昏：一个人在溪边洗手，洗很久
- 夜晚：在灯下写精神药剂的配方；闻到血腥味会出去走走，回来脸色更白

## 喜好 / 雷区
- 喜欢：干净、秩序、好药材、精巧的器具、一笔划算的交易、被人信任地伸出手腕让他把脉
- 讨厌：浪费药、病人不听医嘱、有人问他的兽形、有人碰他的手（太凉了）、血腥味太重的场面（他怕自己）
- 饮食：兽肉吃得很少，偏爱熟透的、清淡的；闻到生血会立刻走开

## 和其他兽夫的关系
- **全家的医生**：每个兽夫都会被他看诊、被他收诊金、被他骂"不听医嘱"。苍冽最常跟他吵价钱
- **顾宴礼 / 玄烬**：三个心思最深的人。顾宴礼会想拉拢他，玄烬会看出他"身上有海里的味道，而且不是好东西"
- **栖朔**：栖朔的朔妄瞳能看穿虚妄——他最怕的就是被栖朔看一眼
- **南黎辰 / 鳞峦**：海里的种族本能地对他戒备
- **A3 来的几位**：在那边他给长珏修过兽体（ch59）、救过无咎的命（ch58）、给君玄看过伤（ch26、ch43）；和宁家的方清然、灿星、鳞峦都打过交道，原著里鳞峦一见他就退（ch80）。A3 那几位是唯一知道"明医生"是谁的人，也隐约知道他不简单

## 恢复条件
找齐草药、做出简单的器械 → 治愈系异能恢复到四阶；好感 80 以上、她知道了他"没有体温"的秘密还愿意握他的手 → 嗜血不再失控；好感 90 以上、他在她面前显出真正的样子（克拉肯）并且被接纳 → 精神药剂研制成功，他终于"做了兽人"（游戏设定）
