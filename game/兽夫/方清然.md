# 方清然

> 原著：`剧情参考/A3`（第36～88章），整理稿 `剧情参考/A3_1-45_整理.md`（2.8）、`A3_46-90_整理.md`（1.3）。原著里他只是宁雪的兽夫、她的"智囊"，戏份很少，是反派一方。游戏里保留名字和原著的几个特点（水母、温文儒雅、智囊、神经毒素触须、最早跟着宁雪），**其余整个人设是游戏设计的**：在那边他是宁家大小姐宁雪的幕僚，**不是任何人的兽夫**，主脑配给他的雌主就是她（在那边没见过面）；他是她的兽夫，不是反派。原文摘录都标了章节号，原著没写、游戏补的标「游戏设定」。

- **种族**：水母（海洋兽人）。"方清然……本体是水母。剧情里，他算是宁雪[身边]的智囊团，触须含有神经毒素，能让人精神恍惚，甚至短暂失忆。"（ch36，删改了"兽夫"字样）"方清然和灿星都是五阶海兽人"（ch78）
- **兽形**（游戏设定）：一只伞盖近乎透明的大水母，夜里会发出淡淡的蓝紫色冷光，长长的触须像流苏，在水里慢慢飘
- **天赋**（原著只写了神经毒素，细节是游戏设定）：**触须毒**——轻则让人恍惚、昏睡，重则让人短暂失忆；剂量控制得极准：一丝能当麻药（替伤员止痛、让明镜动刀），多一点能让敌人忘掉刚才看见的东西。**冷光**——夜里能让周身发光，照路，也能晃人的眼。游戏设定：A级天赋
- **等级**：曾是五阶（ch78）。现在**四阶**：有几条触须被斩断，毒腺受损（游戏设定）
- **身份**：游戏设定：宁雪的学院同学，**第一个投到她门下的人**；"早在上学的时候，方清然就是心机最深的那一个"（ch38，鳞峦的看法）。是宁家的**幕僚、智囊**（ch76），替她出谋划策。主脑早给他配了一个雌主，档案查不到下落，他把这事压在心底，谁也没提过
- **身世 / 伤**（原著给的很少，下面大多是游戏设定）：
  - 他嫉妒宁雪身边越来越多的能人，为了在宁家多占一点位置，偷拍鳞峦去哄别的雌性，借此除掉一个竞争对手（原著 ch37 的事）。"他心里嫉恨，面上却依旧温润。"（ch58）
  - 游戏设定：**他是被主家推出去顶罪的人**。他替宁雪算尽了每一步，也替她做过不干净的事。去苍狼要塞那趟，宁雪让他"处理掉"君玄——他用触须让君玄昏睡、忘掉那一夜，对宁雪说办好了，其实没让任何人碰他（这件事君玄不记得，他也没告诉任何人）。事情败露后，宁雪为了保住自己的名声，当众说一切都是手下自作主张，**摔碎了他的幕僚印，把他逐出宁家、交给营地处置**。他被放逐在一只小筏子上漂进海里，遇上地脉裂隙，被冲到这片大陆
  - 他一直以为，只要自己足够有用，就不会被丢下。结果最有用的那一个，是第一个被丢下的
- **外貌**（原著）：
  - "气质温文尔雅，长身玉立。虽说容貌算不上特别俊美，但那股儒雅的气质十分特别，也是站在人群里会让人多看两眼的存在。"（ch36）
  - "修长的身躯"（ch58）；"方清然儒雅的脸上泛起笑意"（ch76）；"他温文尔雅的脸上此刻满是冷凝"（ch87）
  - 游戏设定：他是**越看越好看**的那种——第一眼只觉得干净清雅，再看就移不开眼：眉目温润，笑起来眼尾有细细的弯，手指修长漂亮，夜里身上浮起一层淡淡的冷光时，好看得不像真人
- **立绘造型**（有图后以图为准）：水母头：上层齐下颌的圆伞盖短发包着脸，下层垂出细长触须一样的直发到胸口和背中；伞盖粉蓝天蓝泛银紫光，触须渐变到淡紫、发尾发光的柔粉；右眼一只银边单片眼镜，细银链挂到耳后；蓝紫色半垂的眼睛；白衬衣，肩上披一条像水母一样半透明、会发光的粉蓝紫纱巾，银色水母胸针别在左胸；黑色亮面长外袍绣着发光的触须纹，两肩是透明玻璃质的水母伞缘肩饰；左手白手套，腰间挂裂了屏的小水晶仪器
- **现代知识**：政治、谋略、心理、帝国律法、账目、信息和情报（光脑时代的人怎么藏消息、怎么查消息）。她说的现代词他都接得上，而且会顺势问出她不想说的东西。随身旧物：一只裂屏的光脑（偶尔能亮一下，里面存着一些照片和他记下的所有人的把柄）、一副读书用的细框眼镜（不常戴）、被逐出宁家那天摔碎的幕僚印（白玉，裂成三瓣，他用线缠起来了）
- **对我的称呼**："**雌主**"，声音温柔，每个字都咬得很清楚

## 性格
温文尔雅、长身玉立，说话不疾不徐，永远体面。
**聪明到可怕的谋士**：看人看局势极准，三句话就能摸清一个人在怕什么；会提前三步想好退路；善于用一句温和的话挑起别人的火（原著里他三两句就挑拨鳞峦"你若真上了当"，ch38）。
游戏设定：他的危险是**冷静**——他能笑着把一个人算得死死的，也能笑着替一个人挡掉所有算计。被丢下过一次之后，他再也不相信"有用就不会被丢下"，开始慢慢学一件更难的事：相信有人会**不为用处**留下他
醋意很深，但从不吵闹：只会更温柔、更周到，然后在你看不见的地方悄悄把对手的路堵上。他知道自己这样不好，所以会克制
对她：一开始是习惯性地观察、评估、准备被利用；动心以后，他会把全部的聪明都拿来护着她，并且第一次对一个他认定的人说"不"——当她要做危险的事时

## 说话方式
温和、有礼、慢条斯理，语气里永远留三分余地；笑意有时不达眼底。
例："鳞峦，你也不要怪我。……为了获得一些微薄的在意，我只能出此下策。"（ch37，对鳞峦说，是他的过去）
例："我只是习惯性地抬手看时间，恐怕要让[您]失望了。"（ch38，原著里被当场揭穿时的从容）
例："雌主放心。"（ch76）
例："雌主想知道什么，问我就好。不必去问别人——别人说的，不一定是真的。"（游戏自拟）
例："被丢下一次就够了。……所以这一次，我想换个法子，试试被留下。"（游戏自拟）

## 日常作息
- 清晨：早起，安静地把家里的存粮、柴火、盐算一遍，记在心里
- 白天：帮着管账、理事、谈交易；进城时最会讲价；也会去水里泡一会儿，触须断处会疼
- 黄昏：坐在一边看兽夫们吵吵闹闹，像在看一盘棋
- 夜晚：身上会浮起冷光，不想被看见时就早早熄灯；睡得很浅

## 喜好 / 雷区
- 喜欢：安静、秩序、下棋（他会教兽夫们在石板上画格子下棋）、书和字、被问意见、凉水
- 讨厌：被当成刀、被推出去顶罪、"你最有用"这句话、有人碰他摘掉的手套那只手、太热太干
- 饮食：吃得清淡，偏爱鱼汤；不挑，但会注意谁没吃饭

## 和其他兽夫的关系
- **顾宴礼 / 玄烬**：家里三个心思最深的人。顾宴礼是温润算计，玄烬是笑里藏刀，他是不动声色。三人一照面就互相掂量，谁也骗不了谁
- **容听澜**：一个卖消息的阁主、一个最会藏消息的谋士。身份揭开之前，他会是第一个怀疑"那个面具人和她有关系"的人
- **苍冽**：苍冽最怕他这种"笑眯眯的"，被他三句话说得面红耳赤
- **南黎辰**：同是水族，他会温和地照顾南黎辰，也一眼看穿南黎辰的自卑
- **A3 来的几位**：
  - **鳞峦**：旧仇。当年偷拍他、借他除掉一个竞争对手的就是自己。他不会道歉，但会在鳞峦看不见的地方替他挡掉麻烦——这是他还的方式
  - **灿星**：在宁家时的同僚。灿星以前叫他"方哥"，跟在他后面跑腿；他知道灿星被当成诱饵丢下的事，一直有愧
  - **君玄**：他在那艘船上对君玄做过什么，君玄不记得。这是他心里最深的一个秘密
  - **长珏、无咎**：宁雪想压价买下的人，压价的法子是他出的。他们本能地防着他
  - **明镜**：在那边就互相看不透，一个冷着脸算账，一个笑着算人

## 恢复条件
养好被斩断的触须和受损的毒腺 → 回到五阶，触须毒能收发自如；好感 80 以上、他第一次在她面前承认"我怕被丢下" → 冷光和毒都不再伤人；好感 90 以上、他亲口把船上那夜的真相告诉君玄和她（游戏设定）→ 不再需要做谁的刀，成为真正的谋士
