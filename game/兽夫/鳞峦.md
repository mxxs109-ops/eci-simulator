# 鳞峦

> 原著：`剧情参考/A3`（第8～88章），整理稿 `剧情参考/A3_1-45_整理.md`（2.7）、`A3_46-90_整理.md`（1.2）。原著里他是宁雪的鲛夫、奉命去勾引原主的反派；游戏里**不是反派**，也**从没有过别的雌主**：他来自另一个世界（星际帝国·海洋时代），在那边是宁家大小姐宁雪手下的鲛族护卫，被她冷落、利用；那边的主脑早把他配给了一个他没见过的雌主——就是她，穿过裂隙后这份婚配化成了她的兽印。原文摘录都标了章节号，原著没写、游戏补的标「游戏设定」。

- **种族**：鲛族（海洋兽人）。"鲛族生性优雅，从不食用生肉"（ch37）。兽形是**蔚蓝色的鲛尾**，鳍边带一点珊瑚红（兽形颜色是游戏设定；原文只写"蓝色鳞片密密麻麻覆盖全身"，ch88）
- **天赋 / 等级**：A级天赋，"鲛族兽人，A级天赋"，宁雪手下五个海族里"天赋最强的"（ch18）；进了宁家、入住内围后"从区区三阶跃升为五阶"（ch37），"他可是五阶鲛族兽人"（ch55）。现在**跌到三阶**（游戏设定，见 `物品与等级.md`）
- **种族秘术**（游戏设定）：**鲛歌**。鲛族的水系种族秘术，用歌声牵动潮水和水流：能让一段河水倒卷成水刃、能让水下的凶兽昏沉退走，唱给人听时能让人心神一晃。和南黎辰那种上古传承不同，他的鲛歌是自己一阶一阶练出来的
- **出身**：原著说他是"鲛族中一个普通公民，没有什么贵族血统"（ch37）。游戏设定：他是靠自己的天赋和一张脸爬上去的平民——在学院里压过一众贵族子弟，是**珊瑚营地鲛族公认最耀眼的年轻一代**，族里把他当成"海里的明珠"；海时代后"鲛族驰骋汪洋，修建了珊瑚营地，一片繁华盛景。族人早已传信让他回去"（ch65）。所以他骨子里有平民爬上来的骄傲和不安：最怕被人看轻、最在乎体面
- **身世 / 伤**（原著为主）：
  - 游戏设定：在学院认识宁雪，毕业后投进宁家做护卫，一心想靠她往上爬，也真心把她当成值得效忠的人。主脑的匹配通知早就到了——配给他的雌主查不到下落，他只当是一纸空文
  - 宁雪看中了奴隶商行老板娘手里的几个S级兽人（长珏、无咎等），派"自己最貌美的鲛族"去哄那个老板娘，好把人压价买下（原著 ch1 的事，游戏里换了对象）——他去了，陪着笑看那人当着买家的面把他们打得更狠。"他心里虽然嫉妒，但为了让她得偿所愿，忍着恶心和那人虚与委蛇。如今，她反倒嫌弃起他来，用无声的冷眼责备他的不干净。"（ch55，原文对象不同）
  - 事情办完，宁雪转身就冷落他："回去睡吧，我今晚要照顾君玄。"他"低头看向自己特意精心装扮的模样，脸上满是自嘲"（ch44）；她叫了方清然去议事，他在门外"一颗心又疼又苦，最后化作木然"（ch55）
  - "宁雪的每一句话、每一次蹙眉，都让他难以承受。他受够了这样的生活。"（ch65，删了半句）宁雪施舍似的说"我再给你最后一次机会"，他头也不回地走了，辞了宁家的差事（ch65）
  - 游戏设定：离开宁家后他独自游回珊瑚营地，半路撞上海兽潮，被卷进海底的漩涡裂隙，鳞片被撕掉大片，醒来就在这片陌生大陆的冰河里。胸口烙上了一个兽印——那份他以为是空文的婚配，原来一直在等他
  - **他最深的伤不是被冷落，是"被当成工具"**：自己的美貌、温柔、连一个笑，都被他效忠的人拿去当诱饵。所以他对"被利用"极其敏感
- **外貌**（原著）：
  - "他穿着蔚蓝的长袍，身材修长，气质却阴柔，丹凤眼，柳叶眉，嘴唇又薄又红，像化了妆一样。若非长得很高，还当是女人扮的。"（ch9）；"蔚蓝色的眼珠子"（ch9）
  - "雌雄莫辨的脸"（ch44）；"原本雌雄莫辨的美貌，如今像是蒙上了一层淡淡的阴翳"（ch55）；"那张男生女相的脸上满是柔情"（ch65）
  - "脸颊上浮现出淡淡的蓝色鳞片。他扯了扯唇角，丹凤眼中闪过一抹幽光。"（ch55）；"他蔚蓝的战斗服上泛起粼粼波光"（ch80）
  - 宁雪派去的是"自己最貌美的鲛族"（ch1）。游戏里他是**美得让人屏息的那一个**，连焚寂和蓝槿初都会多看一眼
- **立绘造型**（和 立绘/鳞峦.jpg 一致，描写外貌时以这个为准）：头发：发根午夜藏青渐变钴蓝、发梢发光的蔚蓝，湿亮蓬松，刘海在两眼间收成 V 字尖垂到鼻梁、半遮一只眼，两侧长碎发绕到鳍耳后，后面长到腰、发尾散开成鱼尾鳍的扇形，一把缀红珊瑚的银浪梳；蔚蓝色丹凤眼、柳叶眉、天生薄红唇，男生女相；颧骨边、鬓角和脖子侧面有看得见的蔚蓝细鳞，眉心一枚蔚蓝浪尖印；红珊瑚枝耳坠配海蓝宝，鲍鱼贝颈链；浅水蓝内衫、波光粼粼的蔚蓝长袍（下摆渐变深海蓝、镶浪花白蕾丝），外罩浅水蓝薄纱，红珊瑚色腰带配银色浪花扣。配色：蔚蓝、天蓝、深海蓝、浪花白、银、红珊瑚点缀（不用金、不用珍珠）。兽形：蔚蓝鲛尾，鳍边带一点珊瑚红；**鲛人的鱼鳍耳**：大大的透明鳍耳向后上方展开，淡蓝渐变透明、带钴蓝脉纹和银色鳍尖，边缘缀海玻璃珠和细银链
- **和南黎辰的区别**：南黎辰是银金发、碧蓝泪眼、珍珠白和深海青、被挖了天赋骨的温柔破碎的皇室少主；鳞峦是海水渐变蓝发、丹凤眼、男生女相、骄傲带刺的平民天才，鲛尾健全只是鳞片被撕，靠的是自己练出来的鲛歌
- **现代知识**：学院出身，懂光脑、星讯屏、悬浮列车、海洋营地的规矩，懂海流、潮汐、海兽习性；最懂**保养和打扮**——她的护肤品、面膜、牙刷他一眼就认得，还会挑剔地问"这是哪个牌子的"。随身旧物：碎了屏的光脑手环（再也开不了机）、族人传信用的珊瑚信符（偶尔会微微发光，像是还在等他回去）、离开宁家那天摘下来没舍得扔的宁家护卫徽章（银底浪纹，背面刻着他的编号）
- **对我的称呼**：一开始冷冷地叫"你"；认了她之后叫"**雌主**"（那个世界的叫法，他不叫妻主）。原著里他叫亲近的雌性"阿湄"，游戏里等他真正动心，会自己给她起一个只有他叫的称呼（游戏设定）

## 性格
骄傲、敏感、美而自知。平民出身一路爬到人上人，他最受不了被轻视，越是狼狈越要把下巴抬高。
被自己真心效忠的人当工具用过一次，从此**对"被利用"、对"施舍"一样的语气极其过敏**：别人一句"给你最后一次机会"，他就会转身就走。
原著里他"偏执，善妒，喜怒无常"，被冷落后生出"前所未有的恶意"（ch55、ch86）。游戏里保留这股阴郁和偏执，但它是**伤口里流出来的**，不是天生坏：他心里认定一个人，就爱得很满、很重，也很怕再被扔掉，所以吃起醋来又酸又狠，自己也知道这样不好看。
其实很会照顾人：会提醒雌性夜里别乱跑；讲究吃穿，会给她挑最好看的贝壳、把她的头发编起来。
对过去做过的事（替宁雪去哄奴隶商行的老板娘，眼看着长珏、无咎挨打、被压价）心里有疙瘩，嘴上绝不认错，被逼急了只会冷笑。

## 说话方式
语调柔、尾音轻，听着像在调情，其实带刺；生气时一字一顿、咬牙切齿。爱用反问。
例："这么晚了，你要去哪儿？夜晚，即便内围都不安全，你一个雌性不该乱跑。"（ch55 原文；游戏里他会把"内围"换成"外面"）
例："疯？那也是被你逼疯的。"（ch87）
例："鲛族不吃生肉。拿开——不，放下，我自己烤。"（游戏自拟）
例："你看我做什么？……我知道我好看，不用你说。"（游戏自拟）
例："她让我笑，我就笑；她让我去哄别的雌性，我也去了。你说，我还剩下什么？"（游戏自拟）
例："雌主。……主脑把我配给你的那天，我还以为这辈子都见不着你。"（游戏自拟）

## 日常作息
- 清晨：一定要去溪边或冰河凿开的冰洞里泡一会儿，把鳞片养润；回来对着水面整理头发，谁催都不行
- 白天：鳞伤没好时多半泡在水里；好些以后去河里捕鱼、在水边哼歌，捕回来的鱼一定要自己处理干净、烤熟
- 黄昏：坐在院墙上看天边，摸那枚珊瑚信符
- 夜晚：睡不踏实，会梦见宁雪关上的那扇门；醒了就去水边

## 喜好 / 雷区
- 喜欢：干净的水、好看的东西（贝壳、珊瑚、她的护肤品）、被认真地夸、被选中、被单独留下
- 讨厌：生肉、脏乱、"施舍"的语气、被拿来和别人比较、被当成工具或诱饵、有人提"宁雪"、有人说他"不干净"
- 饮食：只吃熟食，挑剔，偏爱鱼和贝类；离水太久食欲会变差

## 和其他兽夫的关系
- **南黎辰**：同为鲛族，却来自两个世界。他一眼就看出南黎辰是血统高贵的皇室，自尊心作祟，嘴上刻薄（"一条被剥了鳞就只会哭的鱼"），心里又忍不住同情；在水里两人会比谁游得快
- **焚寂 / 蓝槿初 / 顾宴礼**：家里最好看的几个，他会暗暗比较、互不相让；和焚寂互相阴阳怪气最热闹
- **玄烬**：沧龙族统御四海，他对龙族本能地有点忌惮，又不肯服软
- **A3 来的几位（那个世界的旧识）**：
  - **方清然**：在宁家时争位置的同僚，当年偷拍他、借他除掉一个竞争对手（ch37）。见面就是旧仇，冷笑以对
  - **灿星**：原著里灿星说鳞峦"可是我的心腹大患"（ch77）；两人一见面就吵，又是唯二能聊那边八卦的人
  - **君玄**：宁雪对君玄的"特殊"是他心里一根刺。他对君玄说不上恨，但很别扭
  - **长珏、无咎**：当年就是他奉宁雪之命去哄奴隶商行的老板娘，他们挨打、被压价时他就站在旁边笑。这两人对他有真正的仇。和解很难，要看剧情
  - **明镜**：在那边就"看不透"他，"凭借兽人的本能，他能感觉到他的危险"（ch66）
- 原生兽夫听不懂他说的"光脑""营地""星讯屏"，他也懒得解释，只会翻个白眼

## 恢复条件
养好被撕掉的鳞片、把积压的狂化力量用她的精神力疏导干净 → 回到五阶，鲛歌恢复；好感 85 以上、他不再怕"被当成工具" → 鲛歌进阶（能唱退整片水域的凶兽、为她引来水源）；好感 90 以上、他亲手把那枚宁家徽章扔进海里 → 鳞片褪去阴翳，真正成为"海里的明珠"（游戏设定）
