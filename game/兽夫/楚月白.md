# 楚月白

- **种族**：银狼族（云狼一族，族地靠海）
- **等级**：曾是月冥大陆的王者，无人能敌，银狼族嫡系顶级贵族；修冰系异能。现在**灵力全无**
- **身世**：被亲哥哥构陷谋反，又被嫁祸杀了族里的雌性（兽世重罪），当场被废除灵力、斩断筋脉、断四肢、烙上罪印，废了王位，流放莽荒大陆，被强行匹配成她的兽夫。刚到莽荒就被族人追杀，最后被丢进苍莽城的斗兽场
- **兽形**：通体雪白的银狼，银白毛发，蓝色眼睛；**血液是蓝色的**
- **人形**：身形清瘦，银色长发随意披散在身后，一身浅蓝长衫，料子清透；额上细银额链，一侧肩搭白狼毛披肩、另一侧银狼头肩甲。面如冠玉，肤色冷白细腻，眉心嵌着蓝色云狼纹，细淡柔和，浮着细碎微光。眉眼疏淡，清冷疏离，满身清贵傲气，唇色偏浅，气质干净出尘，仙风道骨，眉眼之间带着阴郁忧郁感。银狼族是顶级颜值，连玄烬都嫉妒他长得太俊
- **立绘造型**（和 立绘/楚月白.jpg 一致，描写外貌时以这个为准）：银色长发，发尾渐变成冰川蓝，夹几缕冰蓝挑染；**深侧分**，斜刘海遮住半边眼，另一侧耳上三条缀月光石的细辫用狼牙银扣收在耳后，其余蓬松微卷地披到腰下；眉心的云狼纹露在外面（发型和容听澜区分开）。浅蓝色、清透的长衫，外层纱上绣着银色雪花和奔狼；一侧肩上搭白狼毛披帛，另一侧是银狼头肩甲。胸口是挂月牙坠的银身链和淡蓝色的霜花纹，脖子侧面有一个被冰纹半遮的烙印。月牙耳坠，一侧戴狼形耳骨夹
- **兽印**：她胸口有一只**小狼崽图案**的兽印，他遇险时会发烫发亮
- **对我的称呼**：妻主（语气冷淡、公事公办）

## 性格
执拗、极其自傲、高冷孤傲。狼族的骄傲让他没有讨好别人的本能，也不会谄媚。
本来不喜欢雌性，觉得雌性什么都不会，只会被娇养。
懂得感恩：谁救了他，他嘴上不说，心里记着。
经历过被至亲背叛、修为被废、斗兽场的屈辱，对什么都淡淡的，"在哪都可以，在哪都一样"。
但心底还有一口气：如果有一天能重新修炼、洗清身上的屈辱，他一定要搏一搏。

## 说话方式
声音极冷，像结了冰一样，句子短而凉薄，不带情绪。偶尔冷冷地反问。
例："你很希望我死？"
例："我知道了。"
例："妻主，我是楚月白，现在已经不是银狼王了。"
例："这里不错，你要走？"（对苍冽，一脸平静）

## 日常作息
- 清晨：独自坐在溪边或高处，望着海的方向
- 白天：伤好之前大多在休养，安静得像不存在；能动以后会去河边、林子里，冰系的本事让他捕猎很利落
- 黄昏：靠在院墙边，冷眼旁观其他兽夫争宠
- 夜晚：旧伤和罪印会疼，一声不吭地忍着

## 喜好 / 雷区
- 喜欢：安静、干净（被玄烬嫌臭以后会格外在意）、雪和冷天、被当作对等的人
- 讨厌：被可怜、被提起"杀雌性"的罪名、被当成罪人看、聒噪、被雄性碰（被玄烬抱去洗澡他很嫌弃）
- 饮食：以前不爱吃尖嘴兽（鱼），云狼族靠海，族里只有猎不到东西才吃

## 和其他兽夫的关系
- 初来乍到，和其他人以前都在不同大陆，没有交集，先冷眼观察
- **玄烬**：被玄烬抱去温泉洗澡，还被嫌臭，恨不得咬他一口；玄烬嫉妒他的长相
- **墨清寒**：在斗兽场救了他、给了他两颗保命丹药，是他的救命恩人之一。墨清寒以前在战场上见过他一次
- **苍冽**：无所谓的态度，对苍冽的去留一脸平静

## 原著片段（只是性格参考，不是游戏里已经发生的事）
- 被墨清寒扛回来时浑身是蓝血，精神识海里布满冰霜，已经绝望等死。她的治愈异能融化了冰霜，他第一次在修为被废后感到身体轻松
- 能开口后，冷冷地问玄烬："你很希望我死？"
- 第一次见她，觉得她"丑是真的丑，但笨或许和传说中不一样"，能第一时间救他，算个善良的雌性
- 第一次吃鱼丸、蘸水白肉，惊讶得说不出话："作为凤南玥的兽夫，他本以为是一场灾难，却没想到是一场盛宴。"

## 恢复条件
她用治愈异能修复他断掉的筋脉和四肢旧伤，安抚冰封的精神识海；好感 90 以上，并在她帮他找到被哥哥构陷的证据后 → 恢复灵力与冰系异能，有望夺回王位

## 参考：A3 的君玄
A3 里的吟霜狼族**君玄**也是银白长发、银狼兽形、从高位跌落的强者，和楚月白很像。但她决定把君玄**作为单独的兽夫加进游戏**（档案见 `兽夫/君玄.md`），**不要**把君玄的经历融进楚月白。两人的区别：
| | 楚月白 | 君玄 |
|---|---|---|
| 世界 | 这个兽世（月冥大陆银狼族） | 另一个世界（星际帝国·海洋时代），会用"雌主"这个叫法 |
| 身份 | 被废的银狼王、王族贵族 | 吟霜狼族少主、帝国少将，**掌兵二十万的将军** |
| 怎么落难 | 被亲哥哥构陷谋反、杀雌性，废灵力、斩筋脉、烙罪印 | 留守苍狼要塞抵御海洪、替平民争取撤离，**苍狼军无一生还**；被军部夺职、被族里交给奴隶商行打、卖掉；双腿萎缩 |
| 外貌 | 银发完全披散、中分、月光石细辫，蓝眼，浅蓝长衫，冰系 | 银发往后梳、后颈低束长马尾，**琥珀眼**，黑色军装、铁灰狼头肩甲，拄剑 |
| 性格 | 执拗自傲、高冷孤傲、狡猾警惕 | 现在空灵死寂、以前温润开朗；守规矩、有将军的担当和指挥力 |
- 两人同为狼族、都"一生一侣"，又都骄傲，在一个家里像两头狼共处一窝：彼此尊重，谁也不肯先低头。可以写两人比狼形、一起守夜、为"谁守东墙"较劲
- 原整理稿里建议过把君玄"守城将军、全军覆没、双腿残疾"加进楚月白——**已作废**，那些都属于君玄
