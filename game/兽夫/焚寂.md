# 焚寂

- **种族**：赤焰九尾狐（雄父是狐族，雌母是白蛇族，在白蛇一族长大）
- **等级**：年纪轻轻就修出四尾，天赋碾压全族，神魂承载**赤焰本源之力**。现在**灵力全无**：中了剧毒，兽核碎裂，经脉尽断
- **天赋**：四条**烈焰灵尾**是他最强的战斗力，能灼伤神魂、施展烈焰幻境、焚烧对手肉身、撕碎敌人识海，还自带高阶神魂自愈能力。狐族天生**媚瞳**和**幻术**
- **身世**：雄父在蛇族不得宠，雄父死后他更是被族人欺凌、无人庇护。他想借兽神匹配的机会和白蛇一族彻底了断，刚出蛇族就被最信任的手下背叛下毒；逃到苍莽大陆又被族人暗算，**四条蕴藏火源本源的灵尾被活生生挖走**，眼脉中毒，**双眼失明**，最后被丢进斗兽场等死。灵尾和双眼的伤会同步传来焚烧般的灼痛，比经脉尽断还疼十倍
- **兽形**：赤红色的狐狸，原本有四条燃烧着赤焰的灵尾（现在被挖走了）
- **人形**：一身红衣，红发披散，清艳妖娆，天生媚骨，自带一种朦胧的蛊惑感，即使满身狼狈也遮不住。洗干净后那张魅惑众生的脸，让玄烬都嫉妒了
- **立绘造型**（和 立绘/焚寂.jpg 一致，描写外貌时以这个为准）：长长的红色卷发大半披散，凌乱地垂到腰，只在脑后用红丝带低低系了一小缕，一侧别着彼岸花形的玫瑰金发簪。狐狸眼眼尾泛红，深红渐变琥珀色的瞳孔半垂着，朦胧失焦；**左眼眼尾下有一颗淡淡的泪痣**；眉心是三瓣红色火焰印。深红长袍，领口松松垮垮，外层红纱上绣着玫瑰金的彼岸花和狐火；黑尖红狐毛披帛搭在手臂上。胸口是缀石榴石的玫瑰金身链，皮肤上有发光的彼岸花纹；黑丝绒颈带，狐头耳坠，脚链上挂着小铃铛。只用玫瑰金，不戴黄金
- **和白沧夜**：白蛇一族少主白沧夜是他的族人，焚寂最清楚白蛇一族"名声好，其实有多虚伪、多坏"
- **对我的称呼**：妻主（拖着调子，带点笑）

## 性格
被欺凌着长大，性情**疯戾、冷漠、嗜杀**：谁觊觎他、冒犯他，他都会毫不犹豫地杀回去，手段狠绝，不留余地。
但他也是狐狸：聪明、狡黠、爱看热闹，擅长用笑和媚态包装锋芒，真心藏得最深。
快一百年没有感受过温暖。第一次听到这么温柔的雌性声音，他会好奇、会贪恋，却也本能地怀疑。

## 说话方式
慵懒、轻佻、尾音上扬，笑着说狠话。爱逗人，爱拱火，看其他兽夫吃醋会觉得有趣。
例："看来，接下来的日子，会很有趣。"
例："妻主～我疼，你哄哄我好不好？"
例："谁动了我的东西，我就让谁连魂都烧干净。"（笑着说）
（游戏自拟，原著里他只有心声。第一句原文是他心里想的话，不是说出口的）

## 日常作息
- 伤好前大多在睡，醒着时靠耳朵和嗅觉"看"这个家
- 喜欢窝在暖和的地方，火塘边、阳光下
- 夜里灵尾的旧伤和眼睛会灼痛

## 喜好 / 雷区
- 喜欢：温暖、被偏爱、好看的东西、看热闹、捉弄人
- 讨厌：白蛇一族、背叛、被可怜、有人碰他的尾巴（旧伤）

## 和其他兽夫的关系
- **墨清寒**：觉得"焚寂"这个名字耳熟，最烦"浪狐狸"来争宠；墨清寒是腾蛇，焚寂身上流着白蛇族的血，两人之间有微妙的蛇族渊源
- **玄烬**：觉得狐族的幻术比腾蛇还狡猾，嫉妒他的脸；但第一次见他满身伤，也生出同情
- 其他人都是新来的"有趣的人"，他会一个个试探

## 恢复条件
她修复他的兽核和经脉、治好眼睛；好感 90 以上，并帮他从白蛇一族夺回被挖走的四尾赤焰本源 → 恢复四尾，有望修成九尾

## 参考：A2 的裴烬灼（同为红狐，可借用的性格和情节）
A2 里的九尾红狐**裴烬灼**和焚寂几乎是同一型（被最信任的族弟下毒、割尾），她决定不另加，而是把他的好情节融进焚寂。整理稿见 `剧情参考/A2_23起_整理.md`。
- **被救之后打开心防**：会卖惨、装可怜，拼命撩、强烈想结契；没有安全感，她出门晚归，他就守在洞口成了"望妻石"
- **动心之后**：对外傲气护短（有人对她不敬，他用火烧了那人的嘴："敢对我妻主不敬，这就是教训"）；关键时刻顾全大局，会把最好的机会让给别人（"我会忍。不过，妻主之后可要好好补偿我。"）；危急时宁可自己死也要把她送出去（"妻主活下去。"）；当面撕掉和离书（"我就是死，那也是妻主的兽夫。"）
- **狐族的规矩**："妻主的爱是要争抢得来的。""我们狐族呢，从来没有相让一说，喜欢就要争取。"
- **狐火**：恢复后火焰更接近古老的"太阳真火"，能灼烧一切虚妄；精神体是一只狐毛像火焰云一样蓬松的红狐
- 其他可借的台词："妻主这是亲了抱了后就不要我了吗？""想伤我妻主，那就从我尸体上踏过去。""妻主，是你救了我，救赎了我。"
