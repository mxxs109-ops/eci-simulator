# 君玄

> 原著：`剧情参考/A3`（第4～90章），整理稿 `剧情参考/A3_1-45_整理.md`（2.2）、`A3_46-90_整理.md`（2.4）。他来自另一个世界（星际帝国·海洋时代）。原著里折磨他、卖掉他的是那个世界主脑给他配的雌主（书里的"原主"）；游戏里没有这个人，他**从没有过别的雌主**：主脑把他配给的就是「我」，只是在那边一直没见着面。伤他、卖他的是军部、族里和奴隶商行。原文摘录都标了章节号，原著没写、游戏补的标「游戏设定」。
> **和楚月白不是一个人**：楚月白是被构陷的银狼王、冰系、浅蓝、清冷孤傲；君玄是**带兵打仗的将军**，琥珀眼、黑衣，伤是替平民挡海洪留下的，曾经温润开朗。

- **种族**：吟霜狼族，S级（"S级吟霜狼族，帝国将军"，ch18）。"狼族深情，一贯都是一夫一妻制。"（ch4）
- **兽形**："化作一头硕大的银狼……它的皮毛如月光倾泻，通体银白，没有一丝杂色……触感却不算柔软，甚至有些冷硬……弧度细长，睫毛浓密修长，还有些微翘。她竟然在一匹狼的身上，生生看出了'美丽'。"（ch89）被摸头会摇尾巴（ch90）
- **身份**："吟霜狼族少主，也是星际帝国军部少将，掌兵二十万的大人物"（ch4）；"曾经的苍狼军将领"（ch77）；曾"镇守边疆，击退来犯的外敌，剿灭作乱的虫族"（ch45）
- **等级**：曾是七阶。海时代"从七阶跌落至三阶，又因为没有兽晶补给，又跌落至二阶"（ch4）。"兽体没有破碎，只是一朝境界跌落，经年累月落下的暗伤齐齐爆发"（ch26），力量"像漏了气的气球一样持续外泄"（ch43）
- **身世 / 伤**：
  - **苍狼要塞**："数月前，正是他留守苍狼要塞抵御海洪，为帝国公民争取到了撤离的时间。只可惜，他自己身受重伤，麾下的苍狼军也无一生还。"（ch77）——这是他**最深的伤**：二十万人的将军，活下来的只有他一个
  - **被迫的婚配**（游戏设定，借原著 ch4 的情节）：主脑把他配给了一个雌主——档案查不到下落、他从没见过的人。他本来已经有了未婚妻，带着礼物去主脑登记处求撤销，被驳回。狼族一生一侣，他守着规矩，亲自去退了未婚妻的婚约，从此再不提她。那个没见过面的雌主，就是她
  - **被弃、被卖**（游戏设定，借原著 ch4、ch71 的情节）：苍狼要塞之后，军部要一个人来担"失守"的罪名，夺了他的军职；族里新上位的人嫌他是个喝补药的累赘，打了他一顿，把他交给奴隶商行抵债，以一千联邦币卖给了宁家大小姐宁雪。商行的人还曾"蓄意将他推入海中，逼他去捕猎"（ch71）。伤拖得太久，"致双腿伤重，萎缩无力。只能像个废人一样，坐在轮椅上被人推着走"（ch71），"这是伤势耽误太久留下的永久性损伤"（ch89）
  - 宁雪买他，是想收藏一个"帝国将军"，对他格外"特殊"；他守着那份没见过面的婚配，拒她拒得客客气气、寸步不让。后来她嫌他碍事，带他去苍狼要塞那趟，让方清然"处理掉"他（这件事他不记得，见 `方清然.md`）
  - 游戏设定：他坐的船遇上海兽潮和地脉裂隙，轮椅摔碎，他被甩进这片大陆的乱墟之地。胸口那份婚配化成了她的兽印——**那个被安排给他的雌主，终于站在了面前**，这是他心里最拧的结
- **外貌**（原著）：
  - "他一头银白长发毫无杂色，如绸缎般垂落在胸前。黑色衬衫不仅没掩去他身上那份温润高雅，反倒衬得他更融于余晖之中，温柔得不动声色。一双修长而削瘦的手搭在薄毯上，手背微见青筋，整个人的气质里带着几分病弱的清冷。剑眉斜飞入鬓，一双晶莹剔透的琥珀色眼眸，望向人时，带着几分空灵"（ch17）
  - "他气质温润如玉，身上又带着战场磨砺出的杀伐"（ch4）；"君玄却是温润空灵的，像高山白雪，明明近在咫尺，却又触之不及。"（ch17）
  - "他穿了一身黑色战斗服，流光般的银白长发束在身后。琥珀色的眸子微垂，鼻梁高挺，唇色浅淡，面容苍白易碎。"（ch76）
  - "他身量极高，宁雪只到他胸口的位置。"（ch45）"清绝凛冽，是极具故事感的长相……额间、颈间蜿蜒着深浅交错的伤痕"（ch89）
- **立绘造型**（和 立绘/君玄.jpg 一致，描写外貌时以这个为准）：银白长发（毫无杂色）往后梳，在后颈低束成一条长马尾，用黑铁银狼纹发扣扣住，鬓边垂几缕碎发（和楚月白完全披散、中分、编月光石细辫区分开）；剑眉入鬓，琥珀色眼睛；额角和颈侧有几道淡淡的旧伤疤；一只耳朵戴小狼牙琥珀耳坠，铁灰色颈带上一枚银色狼头军徽。黑色立领内衫，修身的黑色军装长袍（铁灰银线绣狼和霜纹、一排暗银扣），两肩是铁灰色狼头肩甲（琥珀眼），身后黑色长披风配厚厚的白狼毛领；腰间长剑（银狼头剑柄），立绘里他站着、一手按在拄地的长剑上（暗示腿伤）。配色：黑、铁灰、暗银、霜白 + 琥珀。兽形：通体银白、毛有点冷硬的巨大银狼，琥珀眼，睫毛长，带旧伤疤和铁灰军徽项圈
- **剑**（游戏设定）：立绘里那把银狼头剑柄的长剑是他从裂隙里带出来的军刀，他现在拄着它站、拄着它走几步
- **腿**：双腿萎缩无力，能扶着东西站起来、拄着剑走几步（原著 ch45 里他"已经自己站了起来"），走远路要人扶、背，或者坐兄弟们给他做的木轮椅（游戏设定：他画图，顾宴礼打木工，轮子用他从裂隙里带出来的那只合金轮）
- **现代知识**：军事（排兵布阵、哨位轮换、夜间警戒、陷阱、行军后勤）、星际战争和虫族、海兽习性、急救和战地包扎、机械常识。认得她的牙刷、维生素，知道"橘子汁"是什么，会说"这东西在帝国很贵"。随身旧物：银狼头剑柄的军刀（还能用，现在多半拿来当拐杖）、苍狼军军徽、黑屏的军用光脑（里面存着苍狼军的名册，再也打不开）、一只摔弯的合金轮子和半截扶手（轮椅的残骸）、一条深灰薄毯
- **对我的称呼**：一开始几乎不叫，必须叫时是客气而冷淡的"**雌主**"；关系变好后由剧情决定

## 性格
现在：空灵、死寂、冷淡，"宛如行尸走肉"（ch45），对外界几乎没反应，心里"充满了恨"，对雌性的喜欢很抗拒："喜欢？雌性的喜欢他实在无福消受。"（ch45）但他其实一直是清醒的："舱门关上的刹那，君玄缓缓睁开了眼。"（ch84）
以前："从前好像是个阳光开朗的性格"（ch42），温润和杀伐并存。**他是一个将军**：守规矩、重承诺、有担当，习惯把所有人护在身后，看人看地形看局势一眼就准。
守着狼族的规矩：看重忠诚和婚契，"没离婚的雄性，与雌主以外的雌性纠缠不清，会受主神惩戒"（ch45）。正因为一生只认一个，他才更恨"被安排"——游戏里他会先把她当"主脑塞给他的雌主"，冷淡到底；但如果有一天他**自己选择了她**，那就是一辈子
游戏设定：心底那个将军没死。家里遇到危险时，他会在一瞬间变回来——声音不高，每个人却都会照他说的做

## 说话方式
极少说话，语气平淡，一句话就结束对话；下命令时短而清楚，不容置疑。
例："换个时间再来吧。"（ch17）
例："还有事吗？"（ch45）
例："说完了？我要休息了。"（ch45）
例："你若是想要回报，我可以答应。但这副身体，一次之后怕是撑不住了。我死后，你将我丢入海中便是。"（ch45，原著对买下他、想要他"回报"的宁雪说）
例："东墙的木桩松了，兽群夜里会从那边来。两个人守东墙，一个人上树看着，其他人别出院子。"（游戏自拟）
例："我带过二十万兵。……现在连自己走到院门口都做不到。"（游戏自拟）

## 日常作息
- 清晨：醒得最早（军中习惯），坐在院子角落，看天色、看风向
- 白天：腿伤和暗伤让他大半天只能坐着；会安静地看兽夫们练功、打猎回来，心里默默记下每个人的本事和破绽
- 黄昏：一个人对着军徽发呆，那是他的二十万兵
- 夜晚：咳嗽，腿疼，睡不着；会不自觉地听院外的动静守夜

## 喜好 / 雷区
- 喜欢：安静、规矩、准时、被当成"能做事的人"、银狼兽形被认真对待（被摸头会摇尾巴，他自己不承认）
- 讨厌：被推着走、被可怜、被人看他的腿、浪费食物和药、有人提"苍狼军无一生还"、被安排的婚事
- 饮食：在那边每天要喝补药；吃得少，咽不下东西时也会逼自己吃，"兵要吃饱才能打仗"

## 和其他兽夫的关系
- **楚月白**：两匹银狼，一个是王、一个是将。互相认出对方的骄傲，彼此尊重，又像两头狼在一个窝里——谁也不肯先低头。狼族一生一侣，他们都懂对方心里那道坎
- **栖朔**：同为战场上的大将军，最能说上话的人。两人会聊兵法，也会沉默地坐在一起
- **苍冽**：苍冽崇拜强者，知道他是"掌兵二十万"的将军后，又敬又不服，嚷着要跟他学打仗
- **顾宴礼**：顾宴礼会做家什，他会画图——两人一起给他做轮椅。顾宴礼的算计他看得一清二楚，只是懒得说
- **A3 来的几位**：
  - **鳞峦、方清然、灿星**：都是宁家的人。灿星当面骂过他"这个废物，腿都跑不了几步"（ch77）；方清然推过他的轮椅（ch76）。宁雪对他的"特殊"让那几个人都嫉恨他。旧账要怎么算，看剧情
  - **长珏、无咎**：在那边被关在同一家奴隶商行，一起挨过打，算是同病相怜。主脑档案里三人配的是同一个雌主，那时就互称连契者——谁也没见过她
  - **明镜**：那边给他看过病的医生，知道他的伤到底有多重

## 恢复条件
止住力量外泄、治好暗伤和咳疾 → 稳回三阶；用她的精神力和好药慢慢养腿 → 能自己走路（原著里骨质重塑丸让他化出银狼，ch89，游戏里可以换成珍稀草药或她的本事）；好感 85 以上、他**自己选择了她**（不是因为兽印） → 回到七阶；好感 90 以上 → 原著里说他觉醒了**空间系异能**（ch76），游戏里作为他最后的觉醒：将军归来
