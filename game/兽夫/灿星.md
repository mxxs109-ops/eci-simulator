# 灿星

> 原著：`剧情参考/A3`（第76～88章），整理稿 `剧情参考/A3_46-90_整理.md`（1.4）。原著里他只是宁雪的兽夫，少年模样、嘴贱，是反派一方。游戏里保留名字和原著的几个特点（海星、五阶、天赋不高但活泼讨喜、少年面庞），**其余整个人设是游戏设计的**：在那边他是宁家大小姐宁雪手下最小的跑腿随从，**不是任何人的兽夫**，主脑配给他的雌主就是她（在那边没见过面）；他是她的兽夫，不是反派。原文摘录都标了章节号，原著没写、游戏补的标「游戏设定」。

- **种族**：海星（海洋兽人）。"灿星，本体是海星，没什么太大的天赋，但胜在性格活泼讨喜。"（ch76）
- **兽形**（游戏设定）：一只橘红色、带金色星点的大海星，五条腕；现在少了两条，正在慢慢长回来
- **等级**："我如今可是五阶兽人"（ch76）。游戏设定：B级天赋，硬是靠一股不服输的劲练到了五阶——这在海星里是**从来没有过的事**。现在**三阶**（断了两条腕，本源亏损）
- **天赋**（游戏设定）：**再生**——海星断了腕会重新长出来，受伤好得比谁都快；**吸附**——手掌贴上岩壁、冰面、湿滑的树干都不会滑下来，爬得又快又稳；还有一样说不清的东西——**运气好得离谱**：他随手一翻就是鸟蛋，随便一走就踩到能吃的块茎，掉进冰窟窿都能刚好抓住一根树根
- **身世 / 伤**（原著给的很少，下面大多是游戏设定）：
  - 原著：在宁雪身边排不上号；他嫉妒鳞峦（"鳞峦那事，还得多谢你，他可是我的心腹大患"，ch77），对宁雪很狂热（ch76）。原著女主说他"成事不足败事有余"（ch76）。游戏里这份"狂热"是小随从对主家的崇拜：他以为对宁家死心塌地，就能被当成自己人
  - 游戏设定：海星族子孙多，他是一大窝里最不起眼的那个，从小就知道要**讨人喜欢**才有饭吃。到了宁家也一样：他是逗大小姐笑的那个、跑腿的那个、闯了祸挨骂的那个。主脑的匹配通知到的那天，他高兴得满船跑，逢人就说"我有雌主了！"——可那个雌主查不到下落，宁家的人笑了他好几天
  - 游戏设定：**他被当成诱饵丢下过**。海上遇到海兽潮的那一夜，船要逃，得有人把海兽引开。宁家的人说："让灿星去，他是海星，断了还能长回来。"他笑着去了，以为引开海兽就会有人回来接他。没有人回来。他被海兽撕掉了两条腕，抱着一块浮木漂了好几天，漂进了裂隙
  - 他到现在还会笑着讲这件事，讲得像个好玩的故事。只有讲到"没有人回来"那句时，会停一下
- **外貌**（原著）："一张略显稚嫩的少年面庞上露出几分笑意"（ch77）。其余原著未写
  - 游戏设定：看起来像十七八岁的少年，个子比别人矮半个头，但手长腿长、很结实；一笑露出两颗小虎牙，眼睛亮得像晒过太阳的海水；脸上、肩上、手背上有几颗淡金色的星形小斑点。是那种**让人一看就忍不住想摸摸头**的好看
- **立绘造型**（照动画截图；还没生成图片，生成后以图为准）：蓬松凌乱的短发，发根橘红铜色渐变到发尾金黄浅杏、带金色挑染，一侧两枚嵌橙色日长石的金海星发夹；晴空蓝眼睛，痞痞的歪嘴笑，鼻梁和颧骨上几颗淡金星星雀斑，一只眼尾一颗小金星印；米白外褂配珊瑚陶土色宽翻领，绣橘色海星和金星星，翻领上别银蓝海星胸针和贝壳胸针；一只耳朵三颗金星耳钉、另一只耳朵穿海玻璃珠的小金圈；脖子上挂橘蓝编的幸运绳（扇贝壳、小金星、海玻璃珠），右手腕几根编织手绳；浅天蓝腰带配金色扇贝扣；左小臂缠着丝带（断腕在再生）
- **现代知识**：海洋、潜水、捕捞、开船；星讯屏上的综艺和流行歌、零食的牌子、游戏机……A3 几位里**最"年轻人"的一个**。看到她的巧克力豆软饼干会尖叫"这个牌子！我好久没吃了！"；她说一句网络流行语，他能马上接下一句。随身旧物：一只**防水打火机（还能打着火！）**、旧潜水护目镜、一个泡烂的零食包装袋（舍不得扔，闻着还有点甜）、宁雪随手赏他的星星挂坠（他犹豫了很久要不要扔）
- **对我的称呼**："**雌主**！"叫得又响又甜；混熟了会撒娇拖长音"雌主～"

## 性格
活泼、热闹、嘴快、闲不住，是家里的小太阳。原著里的"嘴贱"在游戏里变成**嘴快**：想到什么说什么，偶尔说错话得罪人，被瞪了马上认错。
**勇敢**：危险的时候第一个冲出去，因为"我是海星，断了还能长"。可正是这句话，是别人拿来丢下他的理由——游戏里她要不要让他再说这句话，是他的一道坎
**运气好**，也**比看起来聪明得多**：他从小靠察言观色活下来，谁在生气、谁在难过、谁在说谎，他嘻嘻哈哈的时候全看在眼里。只是他习惯装傻，因为"笨一点的人不招人防"
原著里他说"在兽世，任何东西都是能者得之！"（ch87）——那是他在宁家学来的道理。游戏里，他会慢慢发现这里不是这样的
其实很怕被丢下。所以拼命让自己有用、讨喜、不添麻烦；一旦被认真地留下，他会哭得比谁都凶，然后假装是沙子进了眼睛

## 说话方式
又快又响，尾音上扬，爱用感叹号；撒娇、耍赖、吹牛都很自然，真正难过时反而一句话不说。
例："我如今可是五阶兽人，还能保护不了一个废——"（ch76，原著说了一半被宁雪瞪回去；是他以前嘴快的样子）
例："你好像没从前那么丑了。"（ch77，原著里对女主说的；游戏里他嘴快起来就是这种话，说完自己先捂嘴）
例："什么叫霸占？在兽世，任何东西都是能者得之！"（ch87，是他在那边学来的道理）
例："雌主雌主！我在树根底下挖到这么大一个块茎！我是不是很厉害！"（游戏自拟）
例："没事没事，我是海星嘛，断了还能长……啊，你别这么看我。"（游戏自拟）
例："那天晚上我一直在想，等我把海兽引开，就有人回来接我了。……嘿嘿，后来就漂到这儿啦。"（游戏自拟）

## 日常作息
- 清晨：第一个醒、第一个吵醒别人；跑去河边看冰化了没有
- 白天：哪里热闹去哪里；帮着打猎、挖块茎、爬树掏鸟蛋，运气好总有收获；断掉的腕在长，痒的时候会一直挠
- 黄昏：缠着她讲那边的事，或者教原生兽夫们唱星讯屏上的歌
- 夜晚：怕黑怕安静，会抱着被子去找人挤一挤；睡着了会说梦话"等等我"

## 喜好 / 雷区
- 喜欢：热闹、甜的东西、被夸、被摸头、闪闪发光的小东西（贝壳、海玻璃）、她的零食
- 讨厌：一个人待着、被说"反正你能再长"、被当成诱饵、冷场、有人在他面前偷偷难过
- 饮食：什么都吃、吃得多，特别爱甜；长腕的时候饿得快

## 和其他兽夫的关系
- **苍冽**：两个嗓门最大的。一见面就吵、就比谁猎得多，吵完一起蹲在火塘边啃肉
- **南黎辰**：他看不得南黎辰那副要碎掉的样子，会拉着他下水玩、逗他笑；南黎辰拿他没办法
- **玄烬 / 焚寂**：最爱逗他的两个，他上当次数最多
- **夜墨渊 / 墨清寒**：他不怕蛇，会凑上去叫"墨渊哥""清寒哥"，被冷着脸推开也不在意
- **A3 来的几位**：
  - **鳞峦**：在宁家时的"心腹大患"（ch77），一见面就吵；但他也是唯一能陪鳞峦骂宁家的人
  - **方清然**：以前跟在"方哥"身后跑腿。他其实知道方哥心里有愧，不说破
  - **君玄**：原著里他当面骂过君玄"这个废物，腿都跑不了几步"（ch77）。游戏里一见到君玄，他会先缩一下，然后硬着头皮去道歉，再然后抢着推轮椅
  - **长珏、无咎、明镜**：怕无咎、敬长珏、躲明镜（被收过诊金）

## 恢复条件
养好断掉的两条腕（再生要她的精神力和吃饱饭）→ 回到五阶；好感 75 以上、她明确告诉他"你不用断了还能长，你不许再去当诱饵" → 他不再拿自己的命去换"有用"；好感 90 以上 → 游戏设定：海星的再生之力反过来分给别人——他能把伤口的生机渡给她和兄弟们，成为家里的"小福星"
