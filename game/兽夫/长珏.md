# 长珏

> 原著：`剧情参考/A3`（第1～90章，戏份最多），整理稿 `剧情参考/A3_1-45_整理.md`（2.1）、`A3_46-90_整理.md`（2.1）。他来自另一个世界（星际帝国·海洋时代）。原著里鞭打他、把他拴在地摊上卖的是那个世界主脑给他配的雌主（书里的"原主"）；游戏里没有这个人，他**从没有过别的雌主**：主脑配给他的就是「我」，在那边从没见过面。鞭打他、卖他的是奴隶商行。原文摘录都标了章节号，原著没写、游戏补的标「游戏设定」。
> **和容听澜不是一个人、也不是一族**：容听澜是冰翡蝎，霜白发、白衣、冰系，北寒城暗阁阁主，藏身份；长珏是**碧玉蝎族族长**，黑发、翠绿复瞳、美人尖，兽体破碎，清冷倔强，明面上的兽夫。

- **种族**：碧玉蝎族，S级陆地兽人，"碧玉蝎族唯一的S级兽人"（ch7）。兽形是"一只通体翠绿、唯有尾钩泛着透明寒光的蝎子"（ch45）。"碧玉蝎族算不上讨人喜欢的种族"（ch45），蝎族、蝠族"都不怎么讨喜，甚至让许多雌性感到抗拒和厌恶"（ch45）
- **身份**：碧玉蝎族**族长**，"庇护族群"（ch47）。族群住在"帝国边陲的小星球，人丁稀少，资源稀缺"（ch7），"还保持着千年前的群居生活"（ch7）；"碧玉蝎族生活在雨林"（ch51），"碧玉蝎族虽地处偏远，却不贫穷"（ch82）
- **等级**：原来六阶（"碧玉蝎族的族长、S级兽人、六阶实力"，ch68）。海时代后"短短数月，从六阶暴跌至三阶"（ch7）。后来**兽体破碎**："我兽体破碎，现在连一阶都算不上。"（ch68）掌心有裂纹，"缝隙间散发着淡淡的光泽，那是兽体破碎加剧的症状"（ch28）
- **本事**：原著有"气刀""气劲"（ch6）。游戏设定：碧玉蝎族的种族天赋是**复瞳**和**尾钩寒毒**——复瞳能在暗处视物、看清极快的动作和细小的破绽；尾钩的毒能麻痹、也能入药（族里世代用自己的毒配药）。兽体破碎后这两样都用不出来
- **身世 / 伤**：
  - 游戏设定（借原著 ch7 的情节）：主脑把他配给了一个雌主，档案查不到下落。他去帝都求官署让族人迁进来，被人骂"癞蛤蟆想吃天鹅肉"（ch7 原话，游戏里是帝都官员说的）
  - 他困在帝都那天族地大雨，淹了巢穴，他想回去被拦下，硬闯，"可惜，他没走掉"（ch7）。海时代后族人生死不明，他"早就不想活了"（ch7）
  - 游戏设定：回族地的路上，实力暴跌的他被奴隶贩子套了锁链，卖进奴隶商行。商行的人鞭打他，"满身鞭痕"，最后用铁链把他拴着摆在地摊上卖，标价一千联邦币（ch1）；宁家来压价的那几天，打得最狠
  - 游戏设定：被拍卖那晚，他对商行老板娘说"那就和我一起死吧"（ch7 原话），想**自爆**同归于尽，被拦下，又被打手一刀刺进后背，结果兽体破碎（ch7–ch9）。成了"废货"，宁家不要了；是无咎半夜撬了锁，把他背出来的
  - 游戏设定：他拖着破碎的兽体出海去找族人，小船被海兽潮掀翻，卷进裂隙，醒来时已经被人捡去，**又一次被铁链拴着，摆在苍莽城的奴隶市场上卖**。胸口多了一个兽印——主脑那份婚配，原来配的就是她
  - **他最深的伤是族人**：作为族长没能护住族群，他觉得自己活着只剩一个用处：找到他们

  - "一双翠绿的眼眸从[她]身上扫过，带着几分冷冽的戾气，转瞬即逝。"（ch1）"近一米九的身量"（ch2）
  - "这张脸，眼睛弧度很漂亮，鼻梁也高，嘴唇虽然白，但是标准的菱形唇。头发很黑，像缎子一样""长珏还有美人尖"（ch10）；"一双翠绿的眼睛，很漂亮，但她清晰看到在他瞳孔一侧，还有一个复瞳！"（ch10）

  - "他素来清冷，极少笑，此刻抿唇浅笑的模样，宛如一树梨花悄然绽放，美不胜收。"（ch74）
  - 身上"遍布伤疤，远远望去，像一尊缝缝补补的破娃娃"（ch62）
- **立绘造型**（和 立绘/长珏.jpg 一致，描写外貌时以这个为准）：**湿漉漉、凌乱的墨黑长发**，前面到胸口、后面到背中，大致中分，额前往后拢露出美人尖，很多细长湿发垂在额头、眼前和脸颊上，两侧贴着头往下垂，碎发贴在鬓角和脖子上；只在强光下泛一点暗碧绿光，不戴发饰；耳坠是暗银链串祖母绿晶石的长耳坠，脖子上几层松垮的暗铁链；**翠绿色眼睛，一侧瞳孔旁有一枚小小的复瞳**，眼尾微红；肤色苍白，唇色浅，菱形唇。一身贴身的**黑色窄袖长衣**（像作战服改成的古装），领口和袖口用碧玉色丝线绣着一只翠绿蝎子，腰间黑色宽腰封、挂一块碧玉族长骨牌；外罩一件深墨绿薄纱长衫。锁骨和手臂上隐约露出旧鞭痕，**掌心有发着淡光的细裂纹**；一只手腕上还挂着一截断掉的铁链环。配色：墨黑、碧玉翠绿、苍白、一点透明寒光（不用金、不用银饰为主）
- **现代知识**：族里过着"千年前的群居生活"，所以他是 A3 那几位里**最不"现代"的一个**：认得治疗舱、营养液、联邦币、光脑，知道帝都是什么样，但很多东西只是听说过；雨林、草药、毒、湿度和温度他最懂（蝎族的巢要"温度大概需要恒定在25度左右……湿度要高，环境要暗，底材最好是细沙或软土"，ch51）。看到她的维生素会认真问"这是营养剂吗"。随身旧物：一截拴过他的断铁链、碧玉族长骨牌、一身破旧衣裳
- **对我的称呼**：一开始叫"你"，冷淡疏离；认可她以后叫"**雌主**"。原著里他后来叫"阿湄"（ch85），游戏里由剧情决定

## 性格
清冷、倔强、骄傲，责任感极强（族长）。被逼到绝境时决绝：自爆、跳海都不犹豫。原文说他"像让人疼惜的小白花"（ch17）。
其实很善良：自己落魄了，看到有人欺负弱者仍会出头（"帝国不在，不代表律法不在"，ch11）。
**不愿欠人情**："治病疗伤的费用，我都会还给你。"（ch42）"我很感激，但我迟早是要走的，所以不想有所亏欠。"（ch62）别人对他好，他第一反应是"她想要什么"，甚至以为对方图他的身体，想用身体"还债"（ch62）。
自卑藏在骄傲底下："你嫌我是兽体破碎的废人吗？"（ch68）蝎族不讨喜，商行嫌他的蝎子样子吓跑买家，化一次兽形打一次，他就再也不化。
纯情：被亲一下心跳会乱，耳尖先红；一旦动心，安静而专一，会默默吃醋、默默护着。
最看重忠诚："雄性的第一课，就是如何对雌性忠诚。"（ch85）

## 说话方式
话少，声音清冽、沙哑，句子短，常带一点冷嘲；越在意越说不出口。
例："那就和我一起死吧。"（ch7，游戏里是对奴隶商行老板娘说的，是他的过去）
例："治病疗伤的费用，我都会还给你。"（ch42）
例："你扶我吧。"（ch42）
例："我很感激，但我迟早是要走的，所以不想有所亏欠。"（ch62）
例："你嫌我是兽体破碎的废人吗？"（ch68）
例："雄性的第一课，就是如何对雌性忠诚。"（ch85，原著对狐堰说；游戏里可以对任何不安分的连契者说）

## 日常作息
- 清晨：沉默地帮着干活，抢着端菜、劈柴，不肯被当成废人
- 白天：兽体破碎，用力就疼，掌心的裂纹会发光；他会去林子里认草药，想找能救族人的东西
- 黄昏：望着远处，想族人；问遍每一个进城的兽夫，有没有见过"翠绿色的蝎子"
- 夜晚：怕冷怕干，喜欢暗而潮湿的角落；旧鞭痕下雨天会疼

## 喜好 / 雷区
- 喜欢：暗、潮湿、温暖（约25度）、细沙或软土、雨声；被当成族长而不是货物；她认真看他兽形的样子
- 讨厌：铁链、被摆出来卖、被嫌弃是蝎子、欠人情、被可怜、有人说"兽体破碎的废人"
- 饮食：吃得不多，但她做的饭会吃干净

## 和其他兽夫的关系
- **容听澜**：两个蝎族，一个碧玉一个冰翡。容听澜知道得更多（暗阁），长珏只觉得这个人身上有同类的气味。身份揭开之后，两人可能是最懂彼此"被嫌弃"的人
- **墨清寒 / 夜墨渊**：蛇不讨喜，蝎更不讨喜。几个"被嫌弃的种族"之间有种不说出口的默契
- **玄烬**：玄烬嘴上爱逗人，见他太较真会故意惹他
- **A3 来的几位**：
  - **无咎**：在那边是连契者（主脑档案里配的是同一个雌主）、算是朋友，是无咎把他从商行背出来的（无咎说"长珏决定的事，没人能阻止"，ch7）
  - **君玄**：关在同一家奴隶商行，同病相怜
  - **鳞峦**：当年鳞峦替宁家去哄商行老板娘压价，他挨鞭子时鳞峦就站在旁边笑。他对鳞峦冷到骨子里
  - **明镜**：那边给他修过兽体（原著约定一个月修复，ch59）。他信明镜的医术，也看得出明镜不简单
  - **方清然、灿星**：宁家的人，戒备

## 恢复条件
治好鞭伤和旧伤；修复破碎的兽体（原著里明镜靠治愈系异能加药材修复，游戏里可以是她的本事、珍稀草药加明镜）→ 回到三阶；复瞳和尾钩寒毒恢复 → 六阶；好感 85 以上，并找到族人的下落（游戏设定：裂隙那头偶尔会甩过来东西，碧玉蝎族也许有人一起掉了进来）→ 好感 90 以上，他愿意在她面前化出兽形，并且不再说"迟早要走" → 碧玉蝎族长归来
