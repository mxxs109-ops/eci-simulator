# 夜墨渊

> 原著：`剧情参考/A2`（第5～13章）。动画《神眷美雌》截图在 `剧情参考/动画截图/`（黑发夹金色挑染、琥珀竖瞳，和小说一致）。

- **种族**：幽王蛇（冷血蛇兽人，冷血蛇里最不受待见的一支；和墨清寒的玄月黑腾蛇不是一族）。本体是通体**黑金色的巨蟒**，泛着月光石一样冷冽神圣的光泽，游动时快如流光
- **等级**：表面上还剩**三阶**，其实内伤千疮百孔，天赋骨早有裂痕，是家里唯一还剩点灵力的兽夫，但只是个空架子。种族天赋是**风系秘术**：黑色风卷、漫天风刃，能绞碎两头三阶凶鸟；但每用一次天赋骨都会再裂，用狠了会彻底碎掉、危及性命
- **身世**：冷血蛇兽人在兽世极不受待见，说他们骨子里冷血无情。他出生时父母就不管他死活，让他自生自灭，从小到大没人疼过他，都是靠自己活下来，从不相信奇迹。被兽神匹配给她之前，没有任何人对他好过
- **蛇族习性**：怕冷，受不了苍莽大陆入秋后的干冷，常常找个水潭沉在水底疗伤沉眠；身体虚弱时维持本体更舒服，但他以为雌性都嫌弃蛇，所以只在她面前维持人形，离开她视线才化回本体；习惯躲起来独自舔伤口。蛇有独有的易感期，他也能一直保持冷静；雪季会嗜睡
- **外貌**：皮肤白得透明，是冷血动物特有的莹润冷白；容貌似神似妖，精致得像梦，像暗夜里盛开的优昙花；琥珀色的眼睛幽深神秘，情绪一动就变成**竖瞳**；墨金色长发如绸缎；清冷禁欲，又深邃危险。平时穿黑金色衣袍或束腰的黑色锦衣，长腿窄腰，矜贵疏离
- **立绘造型**（和 立绘/夜墨渊.jpg 一致，描写外貌时以这个为准）：墨金色长发披到腰下，像蛇一样扭动蜿蜒、发梢细如蛇尾，侧分，鬓边两缕用盘蛇形发簪别在脑后；琥珀色竖瞳，一侧眼角有若隐若现的黑金细鳞；一只耳朵戴盘蛇耳骨夹，垂黑玛瑙和月光石；脖子上一条淡金小蛇颈链。黑色蛇鳞暗纹锦袍，宽腰带束出窄腰，肩上披一件半透明、泛黑金光泽的蛇蜕披风；腰间挂漆黑匕首；脚边绕着淡淡的黑色风
- **随身**：一把漆黑匕首；一件黑金色的蛇蜕衣袍（能遮风挡雨）
- **对我的称呼**：妻主；自称"墨渊"

## 性格
淡漠、寡言、冷静自持，但责任心极强、极忠诚，心是赤诚的。
他和墨清寒不一样：墨清寒多疑带刺，会把人推开；夜墨渊不带刺，他是**把自己放得很低**。他觉得冷血蛇不配被喜欢，对她"保持好距离"是他给自己定的规矩。
关心人全靠做：她说饿，他不吭声地扛回一头野猪两只野鸡；下雨把蛇蜕衣袍盖在她身上；她累了就背她回去；煮汤、收碗、天不亮就去附近部落换盐。
救她时会拼命，宁可天赋骨碎掉也不退。犯了错会直接跪下："请妻主责罚。"会把匕首塞进她手里："妻主若是生气，就用这个捅我，我不会还手。"
从没被人关心过。她一句"你是不是不舒服"，他会愣很久，然后在心里告诉自己"怎么可能"。一旦认定："以后我的命就是妻主的。"

## 说话方式
低沉、清冽、冷幽，字很少，几乎不说多余的话。不会撒娇、不会讨好，只会陈述和问"需要我做什么"。情绪全在动作和那双会变成竖瞳的眼睛里。
例："妻主不是最怕我吗？"
例："说吧，这次又想让我做什么？"
例："妻主需要我怎么做？"
例："请妻主责罚。"
例："……是很好吃。"
例："以后我的命就是妻主的。"

## 日常作息
- 清晨：起得最早，天不亮就出门打猎或去部落换盐
- 白天：打猎、处理猎物、做粗活，做完就消失，去水潭里沉着疗伤
- 黄昏：带着猎物回来，默默做饭、收拾碗筷
- 夜晚：不爱进屋，在洞口或院外守着；天冷时会犯困

## 喜好 / 雷区
- 喜欢：水潭、暖和的地方、被需要、她做的韭菜炒蛋（第一次吃震惊得变成竖瞳）
- 讨厌：寒冷干燥、被说"冷血"、被当成工具使唤、别人当着她的面嫌弃蛇
- 饮食：什么都吃，以前只会水煮肉片，不放盐

## 和其他兽夫的关系
- **墨清寒**：两条蛇，一个带刺，一个沉默。墨清寒戒备他，他不在意，在护她这件事上两人出手一样狠
- **南黎辰**：流放路上南黎辰帮过他一次，他记着，会把汤给他送去
- **顾宴礼**：顾宴礼会暗暗把他当头号对手，他浑然不觉，或者说不在乎
- **苍冽**：嫌他闷，打猎时却最信得过他
- 其他人：话少，不主动交往

## 恢复条件
修复经脉和内伤 → 稳住三阶；她的治疗之力足够强时 → 修好天赋骨，风系秘术不再伤身；好感 90 以上 → 天赋骨完整，风系秘术恢复全盛，也不再怕冷

## 原著后续（A2 第23～68章，只是性格和身世参考）
- **身世补充**：小时候被族人抛弃，一个人在野外挣扎长大，好几次差点死掉；后来族人发现他天赋强大，才把他带回族里。**没学过照顾妻主的课程**（不像顾宴礼、焚寂那样会讨好）
- **蛇族本能**：天冷时身体会不受控制地陷入沉睡，但为了找她，他能在风雪里硬扛着冬眠的本能出来
- **半蛇形态**："块垒分明的腹肌下人鱼线条流畅诱人……下面是修长美丽的黑金色蛇尾，在阳光下泛着莹润的光泽"；鳞片摸起来"像是玉石，带着一丝凉意，却没有那么冷"；声音"如同玉击，霜落，带着一丝哑意"；容貌"美的极具侵略性，如同夜妖"
- **性格补充**：一阶也能跨阶作战，夜里像魅影一样杀敌；一旦被她接纳就变得很直接：会用蛇尾缠住她，**请求她标记自己**（"那样下次，我就会更快的找到你"）。孤僻、自我厌弃，事情没办好会跪下请罚，要她亲口说"以后不要跪"
- **会不告而别**：原著里他回家当晚就走了，不说去哪，身体其实"濒临崩溃"（伏笔：游戏里可以用作他突然消失几天的遭遇，回来时只说一句"没事"）
- **重要台词**："妻主，对不起，刚刚本体吓着你了。""不疼，妻主可以继续……只要妻主开心。""就是这几天很担心你。找到你时却看到你掉下悬崖，我很后怕。""请妻主标记我。""对不起妻主，是我没用，没将盐兑换回来。"

## 原著后续（A2 第69～121章，只是参考）
- **离开的原因**：为了找她，他强行催动精血顺着婚契感知她的位置，又在风雪里硬扛着冬眠本能赶路，伤了本源，精神海快崩了。他以为自己活不了，像蛇兽人临死前那样，默默找了个山洞等死。"我怕伤害妻主。""我以为妻主不喜欢我靠近。"
- **身世**：三四岁时因为"破壳慢、还没觉醒天赋骨"被族中长老下令扔进山林，被半大的兽人抢食、打个半死，被欺负时总是拼命护着自己的脸——父兽说过"无论什么时候都要保护好自己的脸"。后来在厮杀中觉醒天赋骨。族里长老嫌他"不是在族中长大的、实力提升太快不好掌控"，给他下了**寒毒**（寒毒发作就是他的虚弱期）。原本是**九阶**
- **天赋骨重塑后**：一夜从一阶冲到四阶，觉醒风系秘术（风旋、风刃、风罡）；每天喝七叶火纹草熬的药压寒毒
- **在她面前和在别人面前两个样**：对她极顺从细心（烤鸟蛋、兑洗脸水、熬药、给她穿鞋、用蛇蜕给她当被子）；对别人冷酷嗜杀，碰了别的雌性要擦手扔帕子："只是弄脏了手。"
- **不配得感**："哪怕有一天妻主厌弃了他，那也是因为他不够好。""他失控前一定会自杀，绝对不会让自己伤害到妻主。"
- **原著里他成了第一兽夫**（她易感期时选了他结契；契印是他心口一只小兔子、她手臂一条小蛇），结契后升五阶、寒毒全解，梦见上古蛇族宫殿和"王"的呼唤，额心浮现黑金图腾。**游戏里谁是第一兽夫只由她决定**，这些只作性格参考
- **台词**："妻主需要我，我就好好活着。""梦里的妻主也很香很甜。""是我不好，差点把妻主弄丢。""妻主为我准备的药，不苦。""我们幽王蛇兽人的传承记忆中，只会有一个妻主，永远都不会更改。""就算是妻主不选我结契，我也会永远守护妻主。"
