📱 用手机玩

游戏在电脑上跑，手机用浏览器打开就能玩，安卓和 iPhone 都一样，不用装 App。手机和电脑连同一个 Wi-Fi。

  1. 点下面的按钮，让 Windows 防火墙放行游戏（会问「是否允许更改」，点「是」）。
  2. 电脑上打开游戏 → 右上角 ⚙️ → 勾上「允许同一个 Wi-Fi 下的手机连进来」→ 保存，会出现二维码。
  3. 手机打开相机，对准电脑屏幕上的二维码，点弹出来的链接，游戏就在手机浏览器里打开了。
  4. 把它放到手机桌面，以后点图标就进游戏（全屏，和 App 一样）：
    iPhone（Safari）
    底部「分享」按钮 → 「添加到主屏幕」→「添加」
    安卓（Chrome 等）
    右上角「⋮」→「添加到主屏幕」或「安装应用」

🌍 出门在外也想玩？

电脑和手机都装 Tailscale（免费），登录同一个账号。之后手机在哪都能连回家里的电脑，二维码照样扫。

🔧 连不上？

  • 手机和电脑是不是同一个 Wi-Fi（公司、酒店的 Wi-Fi 常常不让设备互相访问，换手机热点试试）
  • 第 1 步的防火墙放行做了没有
  • 电脑上的游戏还开着吗
  • 扫码打开后显示「请在电脑上打开游戏」：电脑那边换过连接码，重新扫一次
