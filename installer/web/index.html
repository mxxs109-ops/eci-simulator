📱 用手机玩

手机浏览器就能玩，不用装 App。手机和电脑连同一个 Wi-Fi。

  1. 让防火墙放行游戏
    点按钮，Windows 会问「是否允许更改」，点「是」。
  2. 打开手机连接
  3. 手机打开相机，扫下面的二维码
    点弹出来的链接，游戏就在手机浏览器里打开了。
  4. 放到手机桌面，以后点图标就进游戏（全屏，和 App 一样）
    iPhone（Safari）
    底部「分享」按钮 →「添加到主屏幕」→「添加」
    安卓（Chrome 等）
    右上角「⋮」→「添加到主屏幕」或「安装应用」

🌍 出门在外也能玩

不在同一个 Wi-Fi 也行：电脑和手机都装 Tailscale（免费），登录同一个账号。

  1. 电脑装 Tailscale
  2. 登录 Tailscale
    浏览器里用 Google / 微软 / 苹果账号登录都行，手机上要登录同一个。
  3. 打开出门连接
  4. 手机装 Tailscale、登录同一个账号，再扫码

🔧 连不上？

  • 手机和电脑是不是同一个 Wi-Fi（公司、酒店的 Wi-Fi 常常不让设备互相访问，换手机热点试试）
  • 第 1 步的防火墙放行做了没有
  • 电脑上的游戏还开着吗
  • 二维码有好几个时，挨个扫一下试试（电脑连着好几个网络）
