谁来当游戏的大脑？

游戏里每一句话都是大语言模型写的。三种选一种：

A. 本地模型（装在你电脑上，免费，不限尺度；要好显卡、大内存，比线上慢）
B. 线上 API（DeepSeek、GPT、Claude、通义……按用量付费，快，任何电脑都能用）
C. Claude Code（有 Claude 订阅、装了 Claude Code 的人用，写得最好）

亲密段落：B、C 写不了的那一截，会自动交给本地模型写（装了的话）。只用 B、C 也能玩，那一段会被跳过。

C. Claude Code

配音（每句话用角色自己的声音读出来）

用开源的 IndexTTS-2.5，在你电脑上跑。要 NVIDIA 显卡、8GB 以上显存、驱动 570 以上、25GB 硬盘。没有也不影响玩，只是没有声音。

用手机玩

游戏还是在电脑上跑，手机只是一个窗口。电脑开着游戏，手机和电脑连同一个 Wi-Fi，就能用手机玩。

  1. 下载安卓 App：GitHub 发布页 里的 eci-simulator.apk（用手机浏览器打开这个页面下载）。
  2. 手机上点下载好的 apk。第一次会提示「不允许安装未知来源的应用」，点「设置」→ 打开「允许来自此来源」，再返回点「安装」。
  3. 点下面的按钮，让 Windows 防火墙放行游戏（会弹一个「是否允许更改」，点「是」）。
  4. 电脑上打开游戏 → 右下角 ⚙️ → 勾上「允许同一个 Wi-Fi 下的手机连进来」→ 保存，会出现二维码。
  5. 手机 App 里点「扫码连接」，对准电脑屏幕上的二维码。第一次会问「允许访问本地网络」，点允许。

出门在外也想玩？

装 Tailscale（免费）：电脑和手机都装、登录同一个账号。之后手机在哪都能连回家里的电脑，二维码照样扫。

连不上？

  • 手机和电脑是不是同一个 Wi-Fi（公司、酒店的 Wi-Fi 常常不让设备互相访问，换手机热点试试）
  • 第 3 步的防火墙放行做了没有
  • 电脑上的游戏黑窗口还开着吗
