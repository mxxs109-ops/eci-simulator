恶雌模拟器

游戏在你的电脑上跑，手机扫码连过去玩。

扫不了码？手动输入地址

电脑上：游戏右下角 ⚙️ → 手机连接，二维码里是一整串地址（带 ?t= 连接码）。扫不了码的话，用手机自带的相机或微信扫一下，复制出来的那串粘贴到这里。

连不上怎么办
  1. 电脑上的游戏开着吗？（桌面「恶雌模拟器」那个黑窗口不能关）
  2. 手机和电脑连的是不是同一个 Wi-Fi？公司、酒店、学校的 Wi-Fi 常常不让设备互相访问，换手机热点或家里的 Wi-Fi 试试。
  3. 电脑上的安装器 →「7 手机」→「放行防火墙」点过没有？
  4. 游戏 ⚙️ 里「允许同一个 Wi-Fi 下的手机连进来」勾上并保存了吗？
  5. 在外面玩：电脑和手机都装 Tailscale，登录同一个账号，再扫一次码。
